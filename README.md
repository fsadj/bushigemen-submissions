# bushigemen-submissions

bushigemen.com 的**社区投稿仓库**。在这里提 PR 投稿，博主审核 merge 后，文章会自动发布到 [bushigemen.com](https://bushigemen.com)。

## 投稿方式
1. 在 `posts/` 目录新建一个 `.md` 文件（或提 PR）；
2. 文件开头 Frontmatter：
   ```markdown
   ---
   title: '文章标题'
   published: 2026-07-23
   description: '一句话摘要'
   tags: ['随笔']
   category: '社区'
   ---
   正文……
   ```
3. 提交 PR → 博主审核 merge → 下次构建自动发布。
